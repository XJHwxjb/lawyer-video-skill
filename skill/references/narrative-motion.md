# 法律口播：叙事、镜头与节奏实操

本指南给制作 Agent 使用。它解决一个常见问题：画面里虽然有会动的数字、图标和人物，但所有元素入场后就停住，几分钟都像同一张讲解幻灯片。先按口播建立事件与事实，再设计看得见的行为，最后决定哪些地方需要图表和文字。以下是方法，不是固定模板；用户要求的风格、人物与改动范围优先。

## 1. 先建立事实表，再决定怎么画

逐句阅读口播或已校对的 SRT。对案件事实、主张、证据、裁判结果分别标记说话时间和来源，特别区分谁做了什么、钱属于什么含义。**人物外观不能自行推断真实姓名、身份、性别或责任**；不确定时使用中性示意，不画成确定的事实。

| 原句及时间 | 主体与对象 | 内容的性质 | 画面要传达什么 | 数据、来源和疑点 |
| --- | --- | --- | --- | --- |
| 提到双方约定一定数额 | 提出人 → 约定双方；原文没说清则留空 | 主张/约定 | 对话或约定关系 | 数额只标“约定”，不能标“实付” |
| 后文说明其中一部分未交付 | 原文指明的付款人与收款人 | 实际交付情况 | 拆开展示约定与实付 | 从材料核对每个数字及其语义，不能自行相减当作已查明事实 |
| 法院对返还作出判断 | 审理机关及原文所述当事人 | 结果 | 文书或天平与结论 | 不把当事人陈述画成法院已认定的事实 |

表里应写原句和真实时间；上表只是字段和虚构情境示范，不是案件事实。数字、身份或证据冲突时，在表中保留疑点；先完成不依赖疑点的部分，重要问题无法由素材判断时向用户核对。概念示意不应制造原稿没有的证据、对话、行为动机或判决。

## 2. 从句子到可制作的镜头

给每个语义单元填写以下字段；短句可合并，但信息转折、行为变化、结论出现要有独立动作节点。每一行应能直接对应时间线和最终画面：

```text
口播开始—结束：
原句/句组：
观众要理解：
主体 → 行为 → 对象：
场景与道具：
动作起始 / 接触或转折 / 完成状态及时间：
信息揭示（文案或数值 / 最早出现的原句时间）：
镜头与转场：
事实来源、未确定项：
最终成片核对结果：
```

例：原句是“保存聊天记录和转账凭证”。可以先让人物操作手机、出现代表聊天记录的文件，再让转账凭证进入档案夹，最后两类材料并排对应。这个画面说明“如何保存”，不代表某个具体案件中这些材料一定存在。若原话只说“保留证据”，不要把示意文书上的时间、人名或内容画成事实。

**完成动作需要有结果。** “递材料”至少表现伸手、接触、材料从交付者移动到接收者、接住并稳定四个状态。若无法真实实现，就改为双方在桌前共同查看材料等中性且可完成的动作，不要把一个始终粘在手上的静态道具写成“已经递交”。道具移动方向应与原句主体一致；画面无法确定主体时用标签或中性构图，避免暗示反向交付。

## 3. 安排冲击力与节奏起伏

冲击力来自观众理解的变化，不是全程快速晃动、闪烁或不断放大。先画出一条情绪线：引出问题 → 事件经过 → 发现关键事实 → 解释判断 → 落到建议；根据原稿调整，不要为套结构改写口播。

| 口播功能 | 画面选择示例 | 声画节奏 |
| --- | --- | --- |
| 开场问题 | 一件与事实有关的道具或对照关系先出现，引发疑问 | 明确视觉焦点；关键信息出现后留一点读懂的时间 |
| 事情经过 | 人物连续行动、道具转移，必要时用时间线串联 | 跟随因果推进，同一动作有准备、过程和结果 |
| 核对事实 | 文件、账目或证据逐件进入，被查看、分组、对应 | 在口播说到该项时再揭示，让观众跟着发现 |
| 法律解释 | 天平、法律书、简洁关系图帮助理解判断条件 | 解释复杂处放慢，区分不同前提，避免图标代替论证 |
| 提醒与收尾 | 人物执行原稿所述的保存、整理等建议 | 收束画面并留出字幕阅读时间，不强行制造高潮 |

选择镜头时交替使用人物全景、双方互动的中景、手与证据特写、信息图或文书近景。只有在语义变化时切换；同一镜头可以通过视线、道具、关系变化或适度推近推进。避免连续多个段落均为“左侧文字 + 右侧固定人物 + 图标淡入”。不要为了凑镜头数让镜头切得观众看不清。

给每段选择不同的动作曲线：接触前略有准备，动作快慢要与力度一致，接触后自然停住或轻微回弹；检查前后镜头的人物位置、朝向、手和道具状态。转场可以使用同一文书带到下一画面、镜头跟随道具、同方向运动衔接或有动机的切换；不要把所有镜头都设置为相同时长的淡入淡出。

## 4. 逐句控制信息揭示

为关键数字、标签和判断单独记录 `revealAt`：先从已经核对的 SRT 或听检时间确定该事实被说到的时刻，再根据语义决定是否允许提前少量铺垫。**铺垫可以是没有结论的道具或问题，不应提前显示尚未解释的关键金额或结论。** 与原声同步优先，不要固定“每隔 N 秒出现一项”。

例如某段口播依次说明“约定数额”“部分未交付”“实际收到数额”：

1. 约定数额说到时，显示带“约定”标签的数字或容器。
2. 说到未交付部分时，才将该部分从视觉关系中区分，并明确标为“未交付”。
3. 说到实际收到时，才显示经素材核实、带“实际收到”标签的数值。不能在前面把约定值标成实际支付，也不能将不同法律含义的数字画成自动可相减的账目。

各节点时间应取当前项目的句界；动画帧用 `时间秒 × 实际 fps` 转换，确保对应场景开始、结束帧均在合法范围内。要使信息读得清：每次只突出观众当前需要理解的一层，较长清单可分组或分镜，缩到目标手机尺寸检查。不要让图表、人物、头像和逐句字幕互相遮挡。

## 5. 制作后如何判断是否仍像幻灯片

从实际导出的成片抽查开头、事件经过、法律解释、收尾各一段；对关键行为连续播放或密集抽帧。逐段回答：

- 关掉字幕，只看画面，能否看懂原稿支持的主要行为？看不懂就补动作或调整构图，不能靠额外大段文字解释。
- 每个镜头入场之后是否还有与口播相关的事件、交互或状态变化？如果只是等下一张图出现，应重排动作和信息揭示；无需让所有元素无意义地持续运动。
- 人物为什么在这里？其动作是否指向当前道具、对象或事实，而不是全片机械挥手？
- 图标是否在说明内容，或只是装饰？需要天平摆动、法槌落槌等动作时，确认 SVG 的对应部件真的在动，而不是整张图一起淡入。
- 重要数字和结论是否在正确语义处出现；画面是否明确区分说法、证据和法院结论？
- 转场前后位置、朝向、手、道具是否连续？是否有手穿过身体、持物不接触、走路跳位或接力方向错误？

验收与声音检查的完整步骤见 [成片验收](delivery-qa.md)。不能播放或听检时，如实记录限制，不能仅凭分镜备注、静帧、音量值或代码声称成片动作和音画观感已通过。
