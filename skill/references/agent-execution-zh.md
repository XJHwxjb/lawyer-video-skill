# 给制作 Agent 的中文执行清单

适用于根据口播和字幕制作法律视频的 Agent。按本次用户的实际要求、工具、路径和素材执行；示例只是方法，不是事实或固定画面。完整口播、关键事实、字幕可读和动作真实始终优先于堆叠动效。此文与[逐步执行指南](workflow-zh.md)、[叙事与节奏](narrative-motion.md)及[成片验收](delivery-qa.md)配合使用。

## 1. 看素材，写时间和事实

1. 列出音频、真人视频、头像、SRT 和参考素材的实际路径、时长、格式、用途；检查文件能打开。原文件保持只读，在用户指定位置建独立项目。无真人视频就如实使用头像；不为静态头像声称有真人口播或口型。
2. 用 ffprobe 或本机等效工具读时长、画幅、帧率和音轨数量。分清真人视频自带音频与外部音频，成片同一口播只播放一次；不为适应镜头裁断或变速原声。
3. SRT 是起点，不代表一定和音频一致。把时间、原句、可确认的主体/动作/对象、数字的性质和来源写成表。约定、请求、实付与判决分别登记；没有确认的数据和身份留空，不能根据人物外形猜测。对照原声核对关键句和字幕；不能试听则报告限制。
4. 不确定事实先标出并继续不依赖它的工作；影响法律含义的差异向用户核对。整理完成后再设计对应画面，不新增案件事实。

## 2. 先做可执行分镜，再写代码

全片从第一句覆盖到最后一句。每行对应一段有明确语义的镜头，示例格式如下：

```text
镜头 03 | 00:00:12.000–00:00:16.000 | 原句：……（填用户真实原句）
人物与动作：谁 → 对谁 → 做什么；道具起点 → 接触 → 终点
动画：开始时间 → 关键动作时间 → 停稳时间；镜头从哪个焦点到哪个焦点
画面信息：标签、数字及 revealAt（仅在原稿支持时）；字幕和真人安全区域
下一镜衔接：人物/道具最后位置、朝向、缩放、层级
资源：使用的真实文件路径或组件名；未确认事实与限制
```

例如口播确实讲到“保存聊天记录和转账凭证”，可以安排人物拿手机、将两个示意文件归档，再切到证据板；不要在示意材料上编造姓名、金额或聊天内容。这一例子仅示范如何写动作，不是说明任何案件已经存在证据。

检查每个镜头：元素出现后是否还有与口播有关的行动或变化？不是每个画面都必须运动，但不能连续多个镜头仅靠文字和小图标淡入后等待。根据内容交替使用人物全景、互动中景、手和道具特写、简图或文书近景；复杂句留出阅读时间。

## 3. 按状态实现每个镜头

1. 优先复用 Skill 自带素材。在目录中实际打开 `assets/legal-svg/catalog.json` 查分类和文件相对路径，再复制所需 SVG 到项目，逐个确认文件存在、能渲染、颜色可见。不要凭图标中文名猜文件名；不要把复制文件等同于画面已使用。天平、法槌、清单可参考 `assets/legal-svg-motion/README.md`；图标作为图片淡入并不等于其内部部件运动。
2. 对人物和道具，按准备、运动、接触或转折、完成和回收安排帧。交接时先决定唯一道具由谁持有、从哪只手移动到哪只手，接触之后由接收方接住；不要使用两份看似相同的道具替代转移。人物行走与交接参考 [示例](character-handoff-example.md)，从当前画面位置开始并保留终点。
3. 由当前帧确定画面。按工程实际 fps 把时间转换为帧，例如 `Math.round(秒数 * fps)`；镜头内的局部帧等于当前帧减去该镜头起始帧。不同组件及转场需明确使用全片帧还是局部帧，不能混用。动作需要限制在对应镜头的有效时间内。
4. 分层构图可使用远景、人物道具和前景；缩放或移动场景时，明确变换原点并检查运动开始、中间、结束处人物、道具和手是否越界或遮挡。**字幕、头像和真人窗口应放在独立于运动场景的稳定图层**，除非用户明确要求其随镜头移动；按输出平台检查安全区，不能仅看静止终点。
5. 使用转场时，沿用前一镜头道具的最后位置、比例和朝向作为后一镜头起点，必要时控制前后遮挡。让纸张、证据或镜头移动对应当前语义；不要对所有镜头套同样的淡入、放大、扫光。转场前后字幕要能读清，信息出现时间服从口播。
6. 如用户要完整成片，约 10 秒的人物或动作预览是内部检查，不等于交付；如果用户明确要求先审样片，交付后暂停。预览发现不自然则先修复，再推广到全片，保留口播时间与事实含义。

## 4. 从最终 MP4 验收，而不是看源码备注

建立检查记录，标注时间、看过什么、结果与修复。请至少覆盖以下类别：

| 类别 | 具体检查 | 不能当作通过的情况 |
| --- | --- | --- |
| 实际镜头 | 从导出文件抽查每段关键帧和全片定间隔缩略图；重点段落连续播放或密集抽帧。 | 只看工程预览、首尾或分镜描述。 |
| 动作和转场 | 看动作开始、中间、接触点、结束，以及转场前后相邻帧；检查手、道具、表情和位置。 | 人物瞬移、道具没换手、动作与口播相反或只检查单张图。 |
| 镜头安全 | 检查推进和平移过程中的字幕、头像、真人、主要信息是否始终清晰且在安全区；缩小到手机尺寸复查。 | 静态终点看似正常，中途遮挡、截字或人物出框。 |
| 数据与节奏 | 对照原句检查主体、数字含义、来源和首次出现时间；选开头、事件和解释段连续检查。 | 用约定冒充实付、提前揭示未解释的数值，或文字和图标长时间不再变化。 |
| 音频和字幕 | 检查源与成片时长、字幕文本和时间；能播放时听开头、中段、结尾与音效点，确认口播清晰。 | 仅凭音量/RMS 相近就断定同步或已听检；叠两份原声。 |
| 真实素材 | 检查最终输出中承诺的头像、SVG、图案和动画均真实出现且用途正确，检查来源与使用权限。 | 文件放进目录但没有绑定到视频，或实际只是静态图片。 |

如果工具或环境不支持连续观看、听检或某种验证，清楚标注未完成；抽帧、波形、时长检查只能提供辅助证据。修改后重新渲染并复查受影响的画面，不把测试代码或未经渲染的结果称为成片。

最终交付用户需要的 MP4 和可编辑工程路径，说明实际时长、画幅、已完成检查及仍有的限制；如果用户只要求分析或样片，按其范围交付。
