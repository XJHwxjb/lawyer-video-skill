# 法律视频 SVG：给制作 Agent 的使用与绘制指南

这套素材用于法律科普视频。先根据口播意思选择图案，再安排人物、道具和动画；不要因为有图标就暗示案件事实已经被认定。所有图标是透明底的独立 SVG，使用 `viewBox="0 0 128 128"`、`fill="none"`、`stroke="currentColor"` 和圆角描边。形象是抽象示意，没有仿制国徽或法徽。

从 [图标目录](../assets/legal-svg/catalog.json) 查询中文名称、类别及文件相对路径；路径以 `assets/legal-svg/` 为基准。例如目录中的 `icons/core/scales.svg` 对应 [正义天平 SVG](../assets/legal-svg/icons/core/scales.svg)。[核心符号](../assets/legal-svg/previews/01-核心法律符号.png)、[案件类型](../assets/legal-svg/previews/02-案件类型.png)、[证据与程序](../assets/legal-svg/previews/03-证据与程序.png)、[辅助元素](../assets/legal-svg/previews/04-辅助与动效元素.png) 和 [两种配色示意](../assets/legal-svg/previews/05-两种风格配色示意.png) 可供视觉查找。预览图仅用于选图；制作视频时使用可缩放的 SVG 源码。

## 先看懂该选哪一类

| 口播内容 | 可以选的图案 | 可做的动作 |
| --- | --- | --- |
| 法律条文、公平与判断 | 法律书、天平、法条文书 | 书页依次描线、天平小幅平衡 |
| 审判、判决程序 | 法院、法槌、证人席 | 建筑线条出现、法槌缓慢落向底座 |
| 签约与合同风险 | 签约合同、笔、断裂合同 | 笔沿签名移动、合同中线断开 |
| 婚姻、亲子与家庭 | 结婚证、家庭、亲子 | 人物轮廓依次出现、文件归档 |
| 劳动关系 | 工牌、公文包、握手、离职文书 | 工牌出现、双方靠近或分离 |
| 取证与举证 | 放大镜、聊天记录、录音、证据夹、证据链 | 放大镜扫过材料，文件逐件归档 |
| 时效、债务与房产 | 日历、沙漏、欠条、钱币、房屋 | 时间进度前进、凭证进入档案 |
| 线上答疑、隐私与风险 | 问号、对勾、锁、警示、盾牌 | 问题出现，再展示记录和核查 |

天平、法槌是视觉隐喻，不代表胜诉、法院已受理或案件已被判定。中国语境使用法院、证人席等简化符号时，应依据口播和真实程序选用，不要把国外陪审团样式当作我国所有案件必有环节。著作权、商标等标记只做概念示意，不要据此声称取得了登记或权利。

## 直接使用

1. 复制所需 `.svg` 到新视频项目；不要修改原始图标。使用 `viewBox` 而非固定宽高缩放，并留出图形周围空白。
2. `currentColor` 的颜色来自 **SVG 自身或其所在文档**的 CSS `color`。将 SVG 源码内联到 HTML / React 时，可以在外层设 `color: #8ec6dd`；若作为独立 `<img src="...svg">`，外层 CSS 的 `color` 通常**不会**传入图片内部，需改用内联 SVG，或在项目副本的 `<svg>` 上显式设置 `color`。不要在原文件中永久写死客户配色。
3. SVG 内的 `<title>` 用于识别和可访问名称。如果是纯装饰图案，可在使用时标注 `aria-hidden="true"`；如果传达内容，应保留有意义的可访问标签。
   核心图案中部分 `<g>` 带有可供动画定位的 `id`。同一页面内联多次时，给每一份实例的 `id` 加不同前缀，并同步修改对该 `id` 的引用；避免不同实例的标识符冲突。简单展示时也可以移除未被引用的分组 `id`。
4. 严肃普法可用深蓝背景与低饱和浅蓝描边；轻松答疑可用暖白背景、深青描边和少量珊瑚色点缀。它们是同一套**描边轮廓**的两种展示，不需要添加复杂渐变。图案缩小后需确认仍能辨认，特别是签字、印章和证书。
5. 这些 SVG 文件只是图形，不会自动动起来。描线通常需要**内联** SVG 并针对里面的线段做动画；作为 `<img>` 引用时不能直接选中其内部路径。复杂图形可先分组或拆成独立路径，让关键部位按顺序出现。

## 让描线动起来：可复制的最小示例

下面是独立示例，修改复制出的项目，不覆盖素材库。`pathLength="1"` 将该路径的描线长度规范化为 1；`progress` 为 0 到 1，0 表示未画出，1 表示画完。多个路径可分别设置不同的起始帧和进度，避免全部机械同时出现。

```tsx
import React from 'react';
import {interpolate, useCurrentFrame} from 'remotion';

export const LineReveal = () => {
  const frame = useCurrentFrame();
  const progress = interpolate(frame, [0, 24], [0, 1], {
    extrapolateLeft: 'clamp', extrapolateRight: 'clamp',
  });
  return <svg viewBox="0 0 128 128" width="180" height="180"
    fill="none" stroke="#8ec6dd" strokeWidth="4" strokeLinecap="round">
    <path d="M26 96 H102 M64 24 V96 M36 45 H92" pathLength={1}
      strokeDasharray={1} strokeDashoffset={1 - progress}/>
  </svg>;
};
```

这只是演示三段线如何出现，并非完整天平；要使用图标库中的天平，应将其路径复制为 JSX（`stroke-width` 改为 `strokeWidth` 等），并分别给要描线的路径设置相同的进度逻辑。图案本身是静态 SVG；具体动画需要在视频项目中编写。对于脉冲圆环、分割线等原本使用 `stroke-dasharray` 的虚线，直接覆盖该属性会改变虚线样式，可改用遮罩做绘制动画，或将虚线分段并分别控制。视频渲染应由当前帧计算动作，保证随机跳帧时画面一致；不要依靠鼠标 hover 或浏览器的实时计时器驱动成片。网站中的 hover 可以作为额外互动，独立于视频时间线实现。天平摆动时将横梁和秤盘按合理结构分组，围绕支点小幅旋转；法槌围绕手柄末端旋转，敲击瞬间要对准底座，再轻微回弹。

## 库中没有需要的图案时：自己画

1. 从口播中找**一个可见对象或行为**，先画大轮廓，再加 2–4 条能帮助辨认的内部线。例如“发出催款通知”：先画信封或手机，再加一条通知标记；不要用凭空出现的金额或人物身份。
2. 建立独立文件：`<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 128 128" fill="none" stroke="currentColor" stroke-width="4" stroke-linecap="round" stroke-linejoin="round"><title>中文名称</title>…</svg>`。把内容尽量放在 12–116 的区域，给描边和运动留余量。
3. 优先用 `path`、`line`、`circle`、`rect` 描出连续、清楚的轮廓；线宽保持一致，转角和端点圆润。减少装饰，把不同部件分组命名；不要把无关形状拼成看不懂的图。
4. 检查对称性、重心与负空间。复杂对象在 128 像素和视频中的实际尺寸各看一次：缩小后若难以辨认，删去细节，增加轮廓差异；不要靠极细线解释重要信息。
5. 把天平横梁、法槌、书页、文件印章等需要运动的部位单独放进 `<g>`；旋转前设置清楚的枢轴，检查旋转时不脱节或穿过底座。描线、入场、停顿、退出应与口播语义相配，不是每个词都弹跳。
6. 用 XML 解析器和浏览器检查文件有效性；至少在深色和浅色背景各预览一次。抽查动画开始、中间、结束帧，再连续播放，检查线条断裂、形状颠倒、抖动、图案超出安全区。

用户指定的风格、构图、素材及平台规范优先。本图标库可做原创改造；其他来源的素材需确认使用许可并保留来源记录。
